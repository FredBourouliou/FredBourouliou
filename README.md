### Hi, I'm Frédéric 👋

#### [Le Cobol](https://github.com/FredBourouliou/le-cobol) — invoicing in COBOL, PDFs in PostScript, UI in HTMX

<a href="https://github.com/FredBourouliou/le-cobol"><img src="https://raw.githubusercontent.com/FredBourouliou/le-cobol/main/screenshots/invoices.png" alt="Le Cobol invoice list" width="560"></a>

Exact decimal arithmetic, one compiled COBOL binary per endpoint behind Apache CGI, ISAM storage, ~30 end-to-end tests. Runs with one `docker run`.
